1. Open the browser. Close pop-ups with X or "Not now". On cookie banners choose Reject or Only necessary.
2. Tap the address bar or search box (usually "Search or type URL").
3. Type the query and press Enter or the keyboard Search key.
4. Check: a list of results with links appears.
5. Tap the best result. Read the page for the answer and scroll if needed.
6. If a sign-in or personal-details form appears, stop and tell the person. Never type a password or code.
7. Stop once the answer is found and tell the person it, with the link. Do not fill or submit forms.
