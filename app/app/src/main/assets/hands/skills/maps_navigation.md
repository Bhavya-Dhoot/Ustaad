1. Open the app. Close pop-ups with X or "Not now". If a location prompt has no such control, stop and tell the person.
2. Tap the search bar (usually "Search here" or "Search") and type the place. Tap the result.
3. Tap Directions, or Go in Waze. Pick a mode only if asked: car, two-wheeler, walk or transit.
4. Check: a route with the time and distance appears at the bottom.
5. If the start point is wrong, tap it and type the start place.
6. Stop once the route shows and tell the person the time and distance. Starting navigation, and any ride booking on the map, is the person's tap.
